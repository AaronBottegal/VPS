OBS WEBSOCKET OP TYPES:

0 - HELLO (RECV)
1 - IDENTIFY (SEND)
2 - IDENTIFIED (RECV)
3 - REIDENTIFY (Event updates here)
4 - (UNUSED)
5 - EVENT (RECV)
6 - REQUEST (SEND) <- US TO IT
7 - REQUEST REPLY (RECV)
8 - REQUEST BATCH (SEND)
9 - REQUEST BATCH REPLY (RECV)

INPUTS - QSTRING VECTOR

INPUT KINDS - QSTRING VECTOR ARRY

FILTER KINDS LIST - QSTRING VECTOR ARRAY
FILTER DEFAULT SETTINGS - QSTRING VECTOR PAIRS ARRAY OF KINDS AND THEIR DEFAULTS
